📌 Multi-Timeframe Supertrend Confluence Strategy

This project is a professional TradingView Pine Script v5 strategy that combines Supertrend, moving averages, and multi-timeframe market analysis to generate structured trading signals.

🚀 Strategy Overview

This system is built using a confluence-based trading model, meaning trades are only executed when multiple technical conditions align.

It includes:

Multi-Timeframe Supertrend analysis (Daily → Yearly)
SMA crossover trend confirmation
Market structure filtering (bull/bear logic)
Long/Short mode selection
Built-in dashboard visualization
🧠 Strategy Logic
📈 Long Entry Conditions

A long trade is triggered when:

Price is above the selected Supertrend timeframe level
SMA fast is above SMA slow (bullish momentum)
Market structure confirms bullish trend alignment
📉 Short Entry Conditions

A short trade is triggered when:

Price is below the Supertrend level
SMA fast is below SMA slow (bearish momentum)
Market structure confirms bearish trend alignment
🔄 Exit Logic

Trades are closed when:

SMA fast crosses below SMA slow (long exit)
SMA fast crosses above SMA slow (short exit)
📊 Multi-Timeframe Analysis

The strategy evaluates Supertrend across:

Daily
Weekly
Monthly
Quarterly
Yearly

This ensures trades align with higher timeframe trend direction.
